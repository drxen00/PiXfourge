Pi-Xfourge

Patch your Creality SpacePi X4 dryer to heat to 95°C instead of the factory 85°C, with your own boot screen. Drop in the official beta file, get a new .lcd back. You don't need to flash the beta first. It all runs in this tab, so your file never leaves your computer.

Alpha firmware.
No warranty.

The firmware's author hasn't finished long-term testing at high temperature. Stay nearby for your first runs, and keep the dryer off flammable surfaces.

Read Is it safe? before you flash.

  1. Add the official beta file

      Where do I get this file?

      It's the beta build from Creality, named v0.2.9_3.1_cspx4.lcd (4,161,192 bytes). It is not the retail firmware on Creality's download page, and Pi-Xfourge can't patch retail or older files. If you don't have it yet, ask @gunfuzled where to get it.

    • Pick a boot screen

      The dryer shows this for 2 seconds at power-on. The warning line "ALPHA FIRMWARE: NO WARRANTY, EXPRESS OR IMPLIED" is always drawn along the bottom edge.

      Checking space…

      Logos and flat colors take little space. Photos and gradients take a lot; if the meter fills up, raise "Simplify colors".

    • Build the firmware

    • Put it on the dryer

      1. Format a microSD card as FAT32. If it asks for an allocation unit size, choose 4096 bytes.
      2. Copy the new .lcd file to the card's top-level folder. It must be the only .lcd file on the card, so don't copy the original beta next to it.
      3. Turn the dryer off, put the card in the display's slot, then turn it on.
      4. Wait for the update to finish. When it's done, remove the card, and turn the dryer off and on again if it asks.
      5. Check it worked: the About screen should say V3.0.1_0, and the temperature keypad should say "Input range: 45~95".

      Going back to stock

      Flash the original v0.2.9_3.1_cspx4.lcd, or a retail file from Creality, the same way.

    Check any firmware file

    Not sure what a .lcd file is, or whether a download got damaged? Drop it here and Pi-Xfourge will tell you what it is and whether its checksums are intact. Nothing is uploaded.
